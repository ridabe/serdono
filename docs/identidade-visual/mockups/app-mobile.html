Sobre este arquivo: mockup de conceito, não implementação. As mesmas telas rodam no portal web com o mesmo código (SPEC §2) — o que muda é o breakpoint: bp.compact usa abas inferiores e coluna única; bp.expanded troca as abas por barra lateral (DS §9.7). Todos os valores visuais vêm de docs/identidade-visual/DESIGN_SYSTEM.md.

Ponto de atenção para a implementação: este preview roda no navegador, onde as fontes carregam via CSS. No app real, React Native não faz fallback automático — Sora e Inter precisam ser empacotadas e carregadas com expo-font antes da primeira renderização, e é exatamente isso que a tela de splash (1) cobre.
